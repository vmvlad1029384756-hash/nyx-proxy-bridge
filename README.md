# NYX Proxy Bridge

Сайт публикуется через Cloudflare Pages из папки `website`.

## Cloudflare Pages
1. Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git.
2. Выбери `vmvlad1029384756-hash/nyx-proxy-bridge`.
3. Framework preset: None; Build command: пусто; Build output directory: `website`.
4. Save and Deploy.

Кнопка загрузки ведёт на последний GitHub Release: `NYXProxyBridge_Setup.exe`. До публикации релиза EXE скачивание не доступно.

Не добавляй в репозиторий личный `profiles.json`, адреса прокси, логины или пароли.

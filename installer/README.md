# Сборка установщика NYX Proxy Bridge

1. Поместите собранное приложение в `installer/payload/NyxProxyBridge.exe`.
2. Откройте вкладку **Actions** репозитория.
3. Выберите **Build NYX Windows installer** и нажмите **Run workflow**.
4. После успешной сборки установщик появится в GitHub Releases как `NYXProxyBridge_Setup.exe`.

Установщик на Inno Setup:
- Windows x64;
- позволяет выбрать диск и папку установки;
- создаёт ярлык в меню «Пуск»;
- предлагает создать ярлык на рабочем столе;
- предлагает запустить программу после установки;
- добавляет стандартное удаление через «Установленные приложения» Windows.

Примечание: установщик пока не подписан цифровым сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение при первом запуске.
